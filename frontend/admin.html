          站点自检

          加载中…

            ⚠️ 这个自检有盲区 —— 它查不了「站点是不是挂了」

            根本原因：自检和被检对象同生共死。 自检代码就跑在这个 Worker 里。Worker 一旦挂了，这段代码也跑不起来 —— 你连后台都打不开，更别说点「立即自检」。

            所以下面这些情况，它一个都报不出来：

            • Worker 整体宕机 / 部署出错
            • Pages 挂了（前端整个打不开）
            • 域名解析 / DNS 出问题
            • Cloudflare 区域性故障
            • SSL 证书过期

            它真正能查的是「Worker 还活着的时候，它的依赖好不好」： 数据库能不能读写、图片存储是否正常、GH_TOKEN 有没有配、GitHub API 通不通。

            这两件事不重叠。 要覆盖前一类，只能靠站外的监控 —— 它从外面敲你的站，敲不通就告警，不依赖你站里任何东西。

            免费方案： UptimeRobot 或 Healthchecks.io， 盯 https://example.com/， 5 分钟一次，敲不通就发邮件。

            还有一点：自检失败时会走已配置的通知渠道，但如果 Worker 整个挂了，那条通知同样发不出来 —— 也是"同生共死"。

            一句话总结：这个面板回答的是「Worker 还能跑的时候，它有没有毛病」； 「Worker 还在不在跑」得由外面的服务来回答。
