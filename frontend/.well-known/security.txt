# 安全联系方式（RFC 9116）
#
# 地址：https://example.com/.well-known/security.txt
#
# 作用：告诉安全研究者「发现漏洞该联系谁」。没有这个文件时，
#       别人就算发现你站有问题也找不到人，只能算了。
#
# ------------------------------------------------------------
# 格式参考：https://www.rfc-editor.org/rfc/rfc9116
#
# Contact 和 Expires 是**必填**，其余可选。
# ------------------------------------------------------------

# 联系方式（必填）。多个可以写多行。
Contact: mailto:Demo@163.com

# 过期时间（必填）。
#
# ⚠️ RFC 要求这个时间**不能超过一年**，用意是逼你定期确认这个文件还有效。
#    过期之后，规范的扫描器会直接忽略整个文件。
#
#    所以它和域名续期一样，是个需要记在日历上的东西 ——
#    域名忘了续期会丢域名，这个忘了续期只是失效，影响小得多。
Expires: 2027-10-16T00:00:00.000Z

# 能接受的语言
Preferred-Languages: zh, en

# 这一份的正式地址（防止有人拿到的是镜像或过期副本）
Canonical: https://example.com/.well-known/security.txt
